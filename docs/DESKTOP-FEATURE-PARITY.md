# DESKTOP FEATURE PARITY — ماتریس نسخهٔ وب و نسخهٔ نصبی

> مبنا: رجیستری واقعی اپ‌ها در `src/lib/os/apps.tsx` (نسخهٔ ۴٫۱).
> معناها: ✅ کامل · 🟡 ناقص/مشروط · ❌ در دسکتاپ کار نمی‌کند · ➖ ناموجود

## معماری

WebView (Tauri v2) → `127.0.0.1:<پورت آزاد>` → سایدکار Node.exe باندل‌شده → سرور Next standalone.
همهٔ اپ‌ها در دسکتاپ «همان کد وب» را اجرا می‌کنند؛ تفاوت فقط در منابع بیرونی و مجوزهاست.

## بسته‌بندی منابع در نصب‌کننده (۴٫۱)

| منبع | داخل نصاب؟ | توضیح |
|---|---|---|
| `.next/standalone` + static + public | ✅ | سرور کامل داخل `server-dist` |
| فونت‌های محلی (Estedad/Vazirmatn/JetBrains) | ✅ | در `public/fonts` — بدون CDN |
| Worker ها (Pyodide worker) | ✅ | در public |
| دیتابیس تازه (schema-only) | ✅ | `server-dist/sanjabos.db` — در AppData کپی می‌شود |
| فایل‌های v86 / کرنل Alpine | ➖ | بار اول از CDN؛ باندل در «Full Offline Pack» آینده |
| Pyodide runtime | ➖ | بار اول از CDN (چند ده مگابایت — باندل حجم نصاب را ~۲× می‌کند) |

## سه سطح قابلیت (قواعد صداقت)

1. **کاملاً آفلاین:** آکادمی‌های متنی، آفیس، نقاشی، بازی‌ها، تنظیمات، راهنمای سنجابک، مرکز یادگیری.
2. **فقط بار اول دانلود:** پایتون (Pyodide)، لینوکس واقعی (v86)، مدل‌های face-api.
3. **ذاتاً آنلاین:** هوش‌یار (کلید کاربر)، سفربُر، آب‌وهوای واقعی، مرکز انتشار.

این تفکیک در راهنمای سنجابک برای هر اپ ثبت شده و در رابط نمایش داده می‌شود.

## سناریوهای تست نصب واقعی (P0 بعدی — نیازمند دستگاه ویندوز)

1. نصب روی Windows 11 تمیز (با/بدون WebView2) → اجرای اول
2. ارتقای نسخهٔ 4.0.0 به 4.1.0 روی نصب موجود → حفظ داده‌های AppData
3. اجرای همهٔ آکادمی‌ها + Pyodide + v86 + ذخیره/بازیابی
4. بستن برنامه → بررسی نبود پردازهٔ Node باقیمانده (Task Manager)
5. Uninstall → پرسش دربارهٔ حذف/نگه‌داشتن داده‌های کاربر
6. نصب مجدد → بازیابی بدون تخریب
