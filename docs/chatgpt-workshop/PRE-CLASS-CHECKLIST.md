# چک‌لیست پیش از اجرای دوره

## حساب و محیط
- [ ] حساب ChatGPT و اتصال اینترنت را با همان دستگاه و مرورگر روز ارائه آزمایش کن.
- [ ] قابلیت‌های Search، فایل، تحلیل داده، تصویر، Study Mode و Projects را جداگانه بررسی کن.
- [ ] مطمئن شو سهمیهٔ رایگان برای دموهای اصلی باقی مانده است.
- [ ] اعلان‌ها، تب‌های خصوصی و اطلاعات حساس را ببند.

## فایل‌های نمونه
- [ ] یک PDF کوتاه، عمومی و غیرمحرمانه آماده کن.
- [ ] یک CSV ساختگی و بدون اطلاعات شخصی آماده کن.
- [ ] یک موضوع به‌روز اما کم‌ریسک برای دمو Search انتخاب کن.
- [ ] برای دمو تصویر، پرامپت و نمونهٔ جایگزین آماده داشته باش.

## پشتیبان دموها
- [ ] برای هر قابلیت یک اسکرین‌شات یا ضبط کوتاه پشتیبان داشته باش.
- [ ] اگر ابزار در حساب فعال نبود، از پرامپت جایگزین و توضیح فرایند استفاده کن.
- [ ] اگر دمو بیش از ۳۰ تا ۴۵ ثانیه معطل شد، به مسیر جایگزین برو.

## اجرای کلاس
- [ ] از مخاطب پاسخ بگیر؛ اسلایدها را روخوانی نکن.
- [ ] دموهای زنده را کوتاه و هدفمند نگه دار.
- [ ] دادهٔ واقعی دانشجویان یا اطلاعات شخصی را آپلود نکن.
- [ ] در پایان از هر نفر بخواه یک عادت استفاده را تغییر دهد.
