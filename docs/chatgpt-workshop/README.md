# راهنمای مدرس دورهٔ کاربردی ChatGPT

این پوشه شامل محتوای اجرایی دورهٔ ۳۷ اسلایدی است.

## فایل‌ها
- [راهنمای کامل مدرس](INSTRUCTOR-GUIDE.md): متن پیشنهادی، کار اجرایی، سؤال تعاملی، هدف و مسیر جایگزین برای تک‌تک اسلایدها.
- [پرامپت‌های دمو](DEMO-PROMPTS.md): متن آماده برای نمایش زنده.
- [چک‌لیست پیش از کلاس](PRE-CLASS-CHECKLIST.md): آماده‌سازی حساب، فایل‌ها، اینترنت و مسیرهای پشتیبان.

## ترتیب پیشنهادی
۱. ارائه را طبق اسلایدها جلو ببر.
۲. راهنما را به‌عنوان cue استفاده کن، نه متن روخوانی.
۳. دموها را پیش از کلاس با حساب واقعی آزمایش کن.
۴. اگر قابلیتی در دسترس نبود، از fallback همان اسلاید استفاده کن.

**اصل دوره:** هدف، قوی‌تر فکرکردن و استفادهٔ مسئولانه از هوش مصنوعی است؛ نه حفظ فهرست قابلیت‌ها یا ترفندهای پرامپت.
