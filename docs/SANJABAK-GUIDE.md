# SANJABAK GUIDE — راهنمای سنجابک

دستیار راهنمای «همه‌جای سیستم» — تفاوت با مربی سنجاب (Coach):
**Coach** مسیر یادگیری درسی می‌سازد؛ **Guide** رابط کاربری، اپ‌ها و محدودیت‌های سیستم را توضیح می‌دهد.

## اجزا

| جزء | فایل | نقش |
|---|---|---|
| رجیستری فراداده | `src/lib/os/help.ts` | تک‌منبع حقیقت: هدف، امکانات، نحوهٔ استفاده، میان‌برها، مجوزها، محل ذخیره، وابستگی اینترنت، محدودیت‌ها، رفع اشکال، اپ‌های مرتبط — برای **همهٔ** اپ‌ها و بازی‌ها |
| اپ راهنما | `src/components/os/apps/guide.tsx` | جستجو/دسته‌بندی، کارت تفصیلی، حالت «این چیه؟»، پرسش هوشمند اختیاری |
| پاسخ هوشمند | `src/app/api/guide/route.ts` | AI اختیاری روی `/api/guide` با زمینهٔ **فقط-خواندنی** از رجیستری؛ نرخ‌محدود؛ بدون کلید/دادهٔ شخصی در کلاینت |
| لنگرهای رابط | `data-help-id` | نوار وظیفه، دکمهٔ شروع، سه دکمهٔ پنجره، میزکار، لینک اسپانسر |

## قواعد محتوا (ضد دروغ)

1. فقط قابلیتِ موجود مستند می‌شود — «دکمه‌ای که نیست معرفی نمی‌شود».
2. هر اپ باید `internet` (none / first-use / required) و `offline` (full / partial / no) داشته باشد.
3. محدودیت‌ها اجباری‌اند: مثلاً ترمینال «شبیه‌ساز آموزشی»، مانیتور «دادهٔ نمایشی»، مرورگر «iframe».
4. `data-help-id` فقط توضیح ثابت برمی‌گرداند؛ به DOM حساس، توکن یا محتوای خصوصی دسترسی ندارد.

## حالت «این چیه؟»

اپ راهنما را باز کن → دکمهٔ «این چیه؟» → روی هر عنصر دارای `data-help-id` کلیک کن.
شنیدن رویدادها در فاز capture و فقط حین فعال‌بودن حالت؛ بعد از خروج، همهٔ listeners پاک می‌شوند.

## Guided Tours

راهنمای کوتاه هر اپ در کارت «چطور استفاده کنم؟» همان نقش را دارد (قابل رد، قابل اجرای دوباره، مزاحم کاربر حرفه‌ای نیست).
تور پله‌ای سراسری (overlay پله‌پله) در نقشهٔ راه است — فعلاً عمداً نهاده نشده تا اپ‌ها را قفل نکند.

## توسعهٔ آینده

- افزودن `data-help-id` به بخش‌های داخلی اپ‌های بزرگ (تنظیمات، آکادمی‌ها)
- تور پله‌ای برای ورود اول
- جستجوی معنایی محلی روی رجیستری (هم‌اکنون جستجوی متنی با کلیدواژه‌هاست)
