## قواعد کاربرد

1. **ثبات بر تنوع مقدم است.** همان مفهوم در همهٔ محصول یک نام دارد؛ مترادف‌چرانیِ زیبایی‌شناسانه ممنوع.
2. **حالت اضافهٔ کلمات لاتین‌پایان:** «کلاس»، «حافظهٔ Heap»، «دستور پاورشل (Cmdlet)».
3. **فعال/مجهول:** «کامپایلر کد را ترجمه می‌کند» بهتر از «کد توسط کامپایلر ترجمه می‌شود».
4. نسخه‌ها و اعداد لاتین می‌مانند: Python 3.12، Rust 1.75، PowerShell 7.
