# BROWSER UPGRADE — سفربُر ۴٫۱

## معماری و حدود صادقانه

نمایش صفحات با **iframe** است و به سیاست امنیتی سایت مقصد (X-Frame-Options / CSP / Same-Origin)
وابسته. سفربُر **هیچ‌کدام از این‌ها را دور نمی‌زند**:

- ❌ بدون Proxy عمومی برای شکستن محدودیت فریم
- ❌ بدون غیرفعال‌کردن حفاظت‌های WebView
- ❌ بدون ادعای «مرورگر Chromium کامل»
- ✅ سایت‌های ضدفریم با پیام شفاف + دکمهٔ «باز کردن بیرونی»
- ✅ تایم‌اوت ۶٫۵ ثانیه به‌عنوان «کند یا مسدود» گزارش می‌شود (iframe راه تشخیص تفکیکی مطمئن نمی‌دهد — صادقانه هشدار می‌دهیم، نه قطع)

sandbox: `allow-scripts allow-same-origin allow-forms allow-popups` + `referrerPolicy=no-referrer`.

## رفع باگ شناخته‌شده: حذف بوکمارک

**قبلاً:** دکمهٔ ✕ روی هر بوکمارک نوار، `toggleBookmark()` (وابسته به URL تب فعال) را صدا می‌زد →
حذفِ بوکمارک اشتباه یا تغییر وضعیت بوکمارکِ صفحهٔ فعلی.

**حالا:** `deleteBookmark(url)` حذف را **بر اساس URL خود بوکمارک** انجام می‌دهد؛ منطق خالص در
`src/lib/os/releases.ts` (`removeBookmark`, `toggleBookmarkFor`) و با ۴ آزمون پوشش داده شده.

## امکانات ۴٫۱

| دسته | موارد |
|---|---|
| تب‌ها | چند تب، تب جدید، بستن، **تکثیر**، **بازگردانی تب بسته‌شده** (Ctrl+Shift+T، تاگل ۱۰تایی)، **بازیابی نشست** بعد از بستن مرورگر |
| ناوبری | عقب/جلو، Reload، خانه، نوار آدرس با **پیشنهاد از تاریخچه و بوکمارک** |
| جستجو | تشخیص URL/عبارت (`classifyAddress`)، انتخاب موتور: DuckDuckGo / Google / Bing / Brave / ویکی‌پدیا (ذخیرهٔ انتخاب)؛ جستجوی سریع ویکی‌پدیا با API باز روی صفحهٔ خانه |
| بوکمارک | تاگل صفحه (Ctrl+D)، نوار بوکمارک سریع، **مدیر بوکمارک**: جستجو، ویرایش عنوان، حذف دقیق، **خروجی/ورودی JSON** |
| تاریخچه | ثبت با زمان، جستجو، پاک‌سازی بازه‌ای (۱ ساعت / ۲۴ ساعت / همه)، نمایش ساعت |
| حریم خصوصی | **حالت خصوصی**: بدون تاریخچه، بدون بوکمارک خودکار، بدون ذخیرهٔ نشست، بدون بازیابی تب — با توضیح صادقانه که جلوی ردیابیِ سایت مقصد/ISP را نمی‌گیرد (حلقهٔ بنفش دور پنجره) |
| زوم | Ctrl+ + / − / 0 با گام ۰٫۱ و نمایش درصد |

## میان‌برهای کیبورد

| کلید | کار |
|---|---|
| `Ctrl+L` | تمرکز روی نوار آدرس |
| `Ctrl+T` / `Ctrl+W` | تب جدید / بستن تب |
| `Ctrl+Shift+T` | بازگردانی تب بسته‌شده |
| `Ctrl+R` | بارگذاری دوباره |
| `Ctrl+D` | بوکمارک (در حالت خصوصی: توضیح شفاف) |
| `Alt+→` / `Alt+←` | عقب / جلو (جهت مطابق دکمه‌های RTL رابط) |
| `Ctrl+ + / − / 0` | زوم بزرگ / کوچک / ریست |

## ذخیره‌سازی (کلیدهای localStorage)

`sunjob-browser-bm-v2` بوکمارک‌ها · `sunjob-browser-hist-v2` تاریخچه (با مهاجرت از نسخه‌های قدیمی) ·
`sunjob-browser-session` نشست تب‌ها · `sunjob-browser-engine` موتور جستجو.
در حالت خصوصی هیچ‌کدام نوشته نمی‌شوند.

## تست

- آزمون‌های واحد: `classifyAddress` (URL/جستجوی فارسی/انگلیسی)، `removeBookmark`، `toggleBookmarkFor` — در `tests/selftest.test.ts`.
- تست دستی E2E در محیط مرورگر: ناوبری، بوکمارک، حالت خصوصی، بازیابی نشست (گزارش در FINAL-ENGINEERING-REPORT).

## محدودیت‌های شناخته‌شده (عمدی و شفاف)

1. دانلود منیجر واقعی (Progress/Cancel/Retry) در این نسخه **نهاده نشد** — iframe رویدادهای دانلود مرورگر میزبان را نمی‌دهد؛ پیاده‌سازی صادقانه نیاز به پل Tauri دارد و در نقشهٔ راه دسکتاپ است.
2. Reader Mode با استخراج محتوا به CORS وابسته است؛ بدون Proxy امن غیرممکن است — به‌جای ادعا، زوم و حذف تب‌های مزاحم با زوم/تمیزکاری رابط انجام می‌شود. نسخهٔ آینده: استخراج فقط برای دامنه‌های موافق.
3. Pin Tab اجرا نشد (اولویت پایین‌تر نسبت به رفع باگ‌های P0).
