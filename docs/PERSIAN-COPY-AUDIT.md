### ۵-۲. درس اول هر آکادمی (اقتباس مستقیم از متن فعلی)

**پایتون `l0-what`** (`python-a.ts:64-95`): متنِ خوب و خط‌به‌خط دارد، اما `example2` با `if a > b: ... else:` باز می‌شود در حالی‌که شرط‌ها در سطح ۳ تدریس می‌شوند — تخطی مستقیم از قاعدهٔ طلایی استاندارد §۱. **اقدام:** مثال اول فقط با `print` بازنویسی شود؛ شبه‌کد فارسی بدون if/else؛ تمرین فقط با print حل‌شدنی.
**تمرین‌ها:** ۲۶ درس هرکدام فقط یک `hint` دارند که اغلب خودِ جواب است (مثلاً `print("سلام پایتون!") — فقط همین`). **اقدام:** تبدیل به سرنخ چندمرحله‌ای.

**پایتون `l0-python`** (`python-a.ts:102-143`): درس دوم مبتدی مطلق با CPython/بایت‌کد/REPL/WebAssembly/Pyodide باز می‌شود و آزمونکش «CPython چیست؟» است. محتوا درست ولی جای آن اینجا نیست. **اقدام:** حفظ محتوا، انتقال به «درس اختیاری: پشت صحنهٔ پایتون» (آخر سطح ۰ یا سطح ۷) با برچسب «اختیاری» + یک یادداشت کوتاه صادقانه در سطح ۰ («در این آکادمی با پایتون واقعی (CPython) داخل مرورگر تمرین می‌کنید»).

**پاورشل `ps-1`** (`powershell-academy.tsx:129-173`): با «پاورشل شل رسمی مایکروسافت روی .NET است» و مقایسهٔ خط لولهٔ bash و `Get-Process | Select-Object -First 3` شروع می‌شود؛ برای دانش‌آموزی که هنوز ترمینال ندیده، نقطهٔ شروع غلطی است. `sampleSolution` بلافاصله نمایش داده می‌شود (`:1716`) و سرنخی وجود ندارد. **اقدام:** بازآرایی کامل مسیر (ترمینال چیست → PowerShell در برابر CMD → اولین دستورها → ... → شیء و خط لوله → فرایندها → اسکریپت امن) + سرنخ چندمرحله‌ای + صداقت شبیه‌ساز.

**راست `rust-what`** (`rust-academy.tsx:83-99`): با «سرعت C و ++C را با امنیت حافظه ترکیب می‌کند... برخلاف Java یا Go، زباله‌روب (GC) ندارد...» شروع می‌شود. مدل درس فقیرترین مدل است: بدون mistakes، بدون تمرین درسی، بدون prereq، بدون خلاصهٔ درسی. **اقدام:** درس ۱ از «برنامه‌نویسی سیستمی چیست» به زبان انسانی + مسیر پیشنهادی (متغیر → تابع → شرط/حلقه → پشته/حافظه → مالکیت به‌صورت سناریویی) + افزودن LessonExtra.

**لینوکس** (`linux-academy.tsx:1429+`): سالم‌ترین شروع (تعریف درون‌متنی هسته/توزیع ✓)؛ ضعف اصلی: ۱۰ مأموریت ترمینال همه `hint = خودِ دستور` (`academy-data.ts:326-336`).
