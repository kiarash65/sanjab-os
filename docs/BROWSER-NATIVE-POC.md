# سفربر واقعی — گزارش آزمایش و معماری (PoC)

> وضعیت: پیاده‌سازی شد (فاز ۱) · شاخه: `feat/desktop-release-browser-upgrade` · تاریخ: ۲۰۲۶-۱۱

## ۱. مسئله

«سفربُر» داخل سان‌جاب‌اواس از `iframe` استفاده می‌کند. سایت‌هایی مثل Google و YouTube و GitHub
با هدرهای امنیتی خودشان (که به احترام امنیت کاربر **دور زده نمی‌شوند**) اجازهٔ نمایش داخل فریم را نمی‌دهند.

## ۲. تست زندهٔ واقعی هدرها (curl — نوامبر ۲۰۲۶)

| سایت | وضعیت | هدر | داخل iframe |
|---|---|---|---|
| google.com | 200 | `X-Frame-Options: SAMEORIGIN` | ❌ بلاک |
| github.com | 200 | `XFO: deny` + `CSP: frame-ancestors 'none'` | ❌ بلاک |
| youtube.com | 200 | `XFO: SAMEORIGIN` | ❌ بلاک |
| lite.duckduckgo.com | 202 | `XFO: SAMEORIGIN` + `frame-ancestors 'self'` | ❌ بلاک |
| bbc.com/persian | 200 | `XFO: DENY` | ❌ بلاک |
| **fa.wikipedia.org** | 200 | — | ✅ کار می‌کند |
| **en.wikipedia.org** | 200 | — | ✅ کار می‌کند |
| **developer.mozilla.org** | 200/302 | — | ✅ کار می‌کند |
| **archive.org** | 200 | — | ✅ کار می‌کند |
| **openstreetmap.org/embed** | 200 | — | ✅ کار می‌کند |
| **wttr.in** | 200 | — | ✅ کار می‌کند |
| example.com | 200 | — | ✅ کار می‌کند |

نتیجه: حتی در مرورگر واقعی هم این محدودیت وجود دارد؛ فرقش این است که مرورگر واقعی
زمینهٔ مرور سطح‌بالا دارد و هدرِ فریم رویش اصلاً اعمال نمی‌شود.

## ۳. راه‌حل فاز ۱ — همین الان (وب + دسکتاپ، API پایدار Tauri 2)

**دستور Rust جدید: `open_native_browser_window(url)`**

- یک `WebviewWindow` **سطح‌بالا و واقعی** با `WebviewUrl::External` می‌سازد
  → روی ویندوز یعنی WebView2 (Chromium واقعی مایکروسافت)، روی لینوکس WebKitGTK.
- چون زمینهٔ مرور top-level است، `X-Frame-Options` اصلاً اعمال نمی‌شود
  → گوگل، یوتیوب، گیت‌هاب و… **واقعاً و کامل** باز می‌شوند.
- امنیت: فقط `http`/`https` مجاز است؛ برچسب یکتا با شمارندهٔ اتمیک؛ بدون پورت عمومی.
- API پایدار Tauri 2 است (نه unstable child-webview، نه Tauri 3/CEF/Electron).

**پل JS:** در `tauri.conf.json` مقدار `app.withGlobalTauri: true` شد؛ سفربُر با
`window.__TAURI__.core.invoke('open_native_browser_window', { url })` صدایش می‌زند.

**رفتار سفربُر الان:**

1. لیست سیاهِ تأییدشدهٔ فریم‌بلاک (از جدول بالا) → **بلافاصله** کارت راهنما نشان داده می‌شود (نه ۶.۵ ثانیه انتظار)
2. کارت راهنما سه گزینه دارد: «پنجرهٔ واقعی مرورگر» (دسکتاپ) / «جستجوی همین سایت در داک‌داک‌گو» / برگشت به خانه
3. برای سایت‌های ناشناخته، تایم‌اوت ۴.۵ ثانیه‌ای سر جای خودش است
4. صفحهٔ خانه: کاشی‌های جدیدِ تأییدشده (Archive.org، MDN، ویکی‌پدیای دسکتاپ) + دکمهٔ نارنجی
   «جستجوی وب با داک‌داک‌گو» که به `embed.duckduckgo.com` (نسخهٔ رسمی فریم‌پذیر DDG) می‌رود
5. در وب (بدون Tauri): همان دکمه‌ها به تب جدید مرورگر می‌روند

## ۴. فاز ۲ — WebView توکار در خود پنجرهٔ سان‌جاب (نیازمند ویندوز واقعی)

دو مسیر بررسی شد؛ هر دو **اینجا قابل تست نیستند** (این محیط لینوکسی بدون GUI ویندوز است) و
تا تست روی ماشین ویندوزی واقعی، ادعای «کار می‌کند» نمی‌کنیم:

| مسیر | وضعیت | ملاحظه |
|---|---|---|
| `windows-webview` (کرِیت رسمی مایکروسافت، WebView2) | منتظر تست ویندوز | میزبانی روی HWND پنجرهٔ Tauri؛ نیاز به همگام‌سازی دستی موقعیت/اندازه با Drag/Resize دسکتاپ شبیه‌سازی‌شده |
| `WebviewBuilder` + `Window::add_child` خود Tauri 2 | unstable feature | ریسک deadlock روی ویندوز در هندلرهای همگام؛ برای انتشار تولیدی هنوز توصیه نمی‌شود |
| Tauri 3 + CEF | رد شد | Alpha است + صدها مگابایت حجم |
| Electron | رد شد | مهاجرت بزرگ بدون منفعت کافی |

توصیه: فاز ۱ را منتشر کنیم؛ فاز ۲ را فقط با PoC روی ویندوز واقعی جلو ببریم.

## ۵. چک‌لیست تست روی ویندوز (برای فاز ۱)

```powershell
bun install
bun run build
bun run build:desktop        # server-dist + node sidecar می‌سازد
cd src-tauri
cargo tauri build            # نصاب NSIS/MSI
```

- [ ] نصاب اجرا شود و SanjabOS بالا بیاید (health-check سرور سبز)
- [ ] منوی شروع ← سفربُر ← گوگل ← کارت راهنما ← «پنجرهٔ واقعی مرورگر» → گوگل کامل رندر شود
- [ ] یوتیوب و گیت‌هاب هم همان‌طور
- [ ] ویکی‌پدیا و Archive.org داخل خود سفربُر (iframe) رندر شوند
- [ ] بستن پنجرهٔ اصلی، پنجره‌های بومی و پردازهٔ Node را هم ببندد

## ۶. چیزهای دیگری که همین شاخه درست شد

- `src-tauri/icons/` **اصلاً وجود نداشت** → بیلد ویندوز قطعاً می‌شکست؛ آیکن‌ها (ico چندسایزی + PNG) از ماسکوت برند ساخته و اضافه شدند
- `resources: ["server-dist/*"]` → `["server-dist"]` (الگوی `dir/*` زیرپوشه‌ها را بازگشتی کپی نمی‌کند — `.next/static` و `public` گم می‌شدند)
- `scripts/build-desktop.mjs` + `bun run build:desktop` → خط تولید تکرارپذیرِ server-dist + node sidecar
- Race condition پورت (bind-then-drop) → تلاش مجدد ۳ باره + تشخیص EADDRINUSE با کشتن فرزند
- CI: اجرا روی `feat/**` و `fix/**`، جابِ واقعی Rust (fmt + cargo check با وابستگی‌های Tauri)،
  چک هم‌خوانی نسخهٔ tauri.conf.json، و «چک سلامت آیکن‌ها» تا دیگر هرگز گم نشوند
