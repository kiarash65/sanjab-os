## ۱. سیستم فونت فارسی (محلی، بدون CDN)

همهٔ فونت‌ها **داخل ریپو** در `public/fonts/` باندل شده‌اند و با `@font-face` + `font-display: swap` در `src/app/globals.css` تعریف می‌شوند. هیچ وابستگی به Google Fonts یا هر CDN دیگری وجود ندارد (`next/font/google` حذف شد). دو فونت اصلی با `<link rel="preload">` در `src/app/layout.tsx` زودتر از همه لود می‌شوند تا CLS نزدیک صفر بماند.

| خانواده | فایل | نوع | سازنده | مجوز |
|---|---|---|---|---|
| **استعداد (Estedad)** | `Estedad-var.woff2` (~۱۲۱KB) | متغیر ۱۰۰–۹۰۰ | امین عابدی — [aminabedi68/Estedad](https://github.com/aminabedi68/Estedad) | SIL OFL 1.1 |
| **وزیرمتن (Vazirmatn)** | `Vazirmatn-var.woff2` (~۱۱۱KB) | متغیر ۱۰۰–۹۰۰ | صابر راستی‌کردار — [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) | SIL OFL 1.1 |
| **وزیرمتن UI** | `Vazirmatn-UI-{Regular,Medium,Bold,Black}.woff2` | استاتیک ۴۰۰/۵۰۰/۷۰۰/۹۰۰ | همان منبع، برش UI برای هماهنگی ارتفاع حروف کنار متن انگلیسی | SIL OFL 1.1 |
| **JetBrains Mono** (کد) | `JetBrainsMono-var.woff2` (~۴۰KB، لاتین) | متغیر ۱۰۰–۸۰۰ | JetBrains | SIL OFL 1.1 |
| پیش‌فرض سیستم | — | استک سیستمی | دستگاه کاربر | — |

- مجوزهای کامل: `public/fonts/LICENSE-Vazirmatn-OFL.txt` و `public/fonts/LICENSE-Estedad-OFL.txt`.
- وزیرمتن UI استاتیک است؛ اسلایدر وزن برای این فونت به وزن‌های موجود (۴۰۰/۵۰۰/۷۰۰/۹۰۰) اسنپ می‌کند — این محدودیت در Settings هم نمایش داده می‌شود.
- JetBrains Mono فقط لاتین است؛ حروف فارسی داخل کد به فونت متن سقوط می‌کنند (fallback عمدی و زیبا).
- فونت پیش‌فرض سیستم «استعداد» است (پیشنهاد اصلی برای متن آموزشی)؛ پیش‌فرض قبلی وزیرمتن با یک کلیک در دسترس است.

## ۲. Design Tokenهای تایپوگرافی

تک منبع حقیقت، متغیرهای CSS روی `:root` که توسط `TypographyProvider` از store ست می‌شوند — **بدون Reload**:

| توکن | نقش |
|---|---|
| `--fa-font-body` | فونت متن و رابط (استعداد/وزیرمتن/وزیرمتن UI/سیستم) |
| `--fa-font-code` | فونت کد (JetBrains Mono یا مونوی سیستم) |
| `--fa-body-size` | اندازهٔ متن مطالعه (۱۳–۲۲px) |
| `--fa-body-weight` | وزن متن مطالعه (clamp داخل بازهٔ فونت) |
| `--fa-line-height` | ارتفاع خط (فشرده ۱٫۷ / راحت ۱٫۹ / باز ۲٫۱۵) |
| `--fa-paragraph-gap` | فاصلهٔ پاراگراف‌ها (خودکار از ارتفاع خط) |
| `--fa-reading-width` | عرض ستون مطالعه (باریک ۶۲۰ / استاندارد ۷۲۰ / پهن ۸۸۰) |
| `--fa-code-size` ، `--fa-code-line-height` | اندازه و ارتفاع کد (۱۱–۱۸px) |

نقشهٔ Tailwind هم وصل است: `--font-sans` ← فونت متن، `--font-mono` ← فونت کد؛ یعنی **۲۰۸ استفاده از `font-mono` در ۳۰ فایل** خودکار از تنظیمات کاربر پیروی می‌کنند. مقیاس رابط (`uiScale` + کنترل‌های بزرگ‌تر) با root `font-size` اعمال می‌شود و متن مطالعه (px) مستقل از آن است.

## ۳. Learning Reader — خوانندهٔ استاندارد آموزش‌ها

`src/components/os/academy/reader.tsx` — استاندارد مشترک مطالعه در همهٔ آکادمی‌ها:

- **پوستهٔ مطالعه**: `.reading-shell` (عرض قابل تنظیم) + `.prose-fa` (تایپوگرافی کامل پاراگراف، تیتر سلسله‌مراتبی، لیست، جدول، نقل‌قول، کد LTR، بلوک‌های نکته/هشدار/ترفند/مثال با `.callout-*`).
- **LearningReader کامل**: فهرست مطالب با اسکرول‌اسپای، نوار پیشرفت داخل درس، بازگشت به آخرین نقطهٔ مطالعه (`sunjob-reader-pos:*`)، حالت فوکوس/مطالعه (حذف عناصر غیرضروری)، کنترل سریع A−/A+ روی همان تنظیمات سراسری، و ردیابی دقیقهٔ مطالعهٔ روز.
- **جایگاه‌ها**: برگه تقلب آکادمی لینوکس با خوانندهٔ کامل (فهرست + فوکوس + ادامه)؛ درس‌های لینوکس/پایتون/راست/هوش مصنوعی/پاورشل با پوستهٔ مطالعه + نوار پیشرفت + «ادامهٔ یادگیری».
- RTL کامل؛ اصطلاحات انگلیسی با `.ltr-inline` / `dir="ltr"` ایزوله می‌شوند؛ کد همیشه LTR است.
- قاعدهٔ ایمنی: `.prose-fa` فقط فرزندان مستقیم را استایل می‌دهد تا کارت‌ها و اجزای داخلی نشکنند.

## ۴. Reading & Typography در Settings

بخش اختصاصی «تایپوگرافی و مطالعه» در Settings Center با **پیش‌نمایش زنده**:

- خانوادهٔ فونت (۴ گزینه با طراح و مجوز)، اندازهٔ متن (پریست + اسلایدر دقیق)، وزن قلم (clamp به بازهٔ فونت انتخابی)، ارتفاع خط، عرض مطالعه، فونت کد + اندازهٔ کد.
- همهٔ تغییرات **فوری** روی کل سیستم و همهٔ آکادمی‌ها اعمال می‌شوند و پس از Refresh می‌مانند (zustand persist + migrate نسخهٔ ۲).
- حداقل اندازه (۱۳px) و کنتراست استاندارد حفظ می‌شود؛ شخصی‌سازی خوانایی را قربانی نمی‌کند.

## ۵. Settings Center

Settings بازطراحی شد: ریل دسته‌بندی (در موبایل چیپ‌های افقی) + ۱۲ بخش:

ظاهر · تایپوگرافی و مطالعه · دسترس‌پذیری · میزکار و رابط · اعلان‌ها و صدا · ترجیحات یادگیری · هوش مصنوعی · حریم خصوصی و داده · ذخیره‌سازی و کارایی · کلیدهای میان‌بر · توسعه‌دهنده · دربارهٔ سیستم

تنظیمات قبلی (کاغذدیواری، چرخش، رنگ، سرگرم‌کننده، صدا، پشتیبان) همه حفظ شده‌اند — چیز تکراری‌ای ساخته نشده.

### دسترس‌پذیری (واقعی و runtime)
کاهش حرکت (`html.fa-reduced-motion` + انیمیشن‌های سیستم) · کنتراست بالا (متن‌های کم‌رنگ روشن، حاشیه‌ها واضح) · کنترل‌های بزرگ‌تر · راهنمای فوکوس کیبورد با رنگ اکسنت · چگالی رابط (فشرده: تسک‌بار/نوار عنوان باریک‌تر) · مقیاس رابط ۹۰–۱۱۵٪.

### ترجیحات یادگیری
هدف روزانهٔ مطالعه (۱۰–۶۰ دقیقه) با نوار پیشرفتِ واقعی از زمان مطالعهٔ ثبت‌شده در خواننده · نمایش/پنهان‌سازی راهنماها.

### داده و پشتیبان
خروجی/ورودی **تنظیمات** (JSON، بدون دادهٔ خصوصی) · پشتیبان کامل (موجود قبلی) · خروجی/ورودی **فقط پیشرفت آموزشی** · حذف داده‌های آموزشی **جدا** از بازنشانی تنظیمات · دکمه‌های خطر با تأیید دومرحله‌ای.

### میان‌برهای سراسری جدید (مثل لینوکس واقعی)
`Ctrl+Alt+T` ترمینال · `Ctrl+Alt+L` قفل صفحه · `Ctrl+Alt+S` تنظیمات · `Esc` بستن منوها.

## ۶. Developer Mode

با کلید «فعال‌سازی» در بخش توسعه‌دهنده روشن/خاموش می‌شود و شامل:

- نسخهٔ سیستم و کد‌نام + نسخهٔ واقعی Runtimeها (import از `package.json`)
- وضعیت APIهای داخلی با پینگ و تأخیر (`/api`، `/api/scores`) · پشتیبانی Worker · FPS زنده · حافظهٔ JS · وضعیت IndexedDB/LocalStorage
- **Log داخلی با سطح‌بندی info/warn/error** (`src/lib/os/devlog.ts`): حلقهٔ ۱۲۰ تایی، ضبط خطاهای window و unhandledrejection، **پاک‌سازی خودکار کلید/توکن/رمز** و کوتاه‌سازی پیام‌ها — هیچ محتوای حساس ذخیره نمی‌شود
- وضعیت بارگذاری فونت‌ها (`document.fonts.check`)
- پرچم‌های ویژگی واقعی + برچسب آزمایشی
- کپی **گزارش فنی** برای تیم توسعه (بدون کلید و دادهٔ شخصی) · پاک‌سازی کش‌های غیرحیاتی (Cache API + session)
